# 组件规格与状态矩阵

组件必须复用。新增页面时**先找已有组件**，确无可用组件再新增，并把新组件登记进下面的清单（保持全系统一套）。推荐目录：`AppShell / Sidebar / Header / StatCard / StatusBadge / DataTable / SearchBar / FilterBar / Drawer / Dialog / EmptyState / LoadingState / ErrorState / Toast / Notification`。

## 1. AppShell（外壳）

- 结构：`Nav (220px) | Header (60px) + Content`。
- 只负责框架、滚动划分、系统状态挂载点；业务内容一律由子页面提供。
- 内容区 padding 24px；内容区是唯一滚动容器。

## 2. Sidebar（左侧导航）

| 项 | 规格 |
|---|---|
| 宽 | 220px（210～240） |
| 项高 | 40～44px；左内边距 16px |
| 图标 | 18px，与文字间距 8px |
| 当前项 | 主色文字 + `--color-primary-soft` 底 + 左侧 3px 主色条 |
| 悬停 | `--color-surface-alt` 底，120ms |
| 徽标 | 未处理数用 Badge（同为 Warning 橙），不改变导航项颜色 |
| 底部 | 系统状态指示（`● 系统正常` / `● 连接异常`） |
| 禁止 | 一级项超过 7 项；在导航里放操作按钮；折叠成纯图标导致识别困难 |

## 3. Header（顶栏）

左侧页面标题（20～22px/600）；右侧固定顺序：系统状态 → 通知（带 Badge）→ 当前用户 → 设置。高度 60px，底边框 1px。**顶栏不放业务操作按钮**——业务操作放在页面标题行右侧。

## 4. StatCard（概览卡片）

```
┌────────────────────┐
│ 待处理              │ 13px 次要色
│ 18                 │ 28～32px/600 主要色
│ ↑ 较昨日 3          │ 12px 辅助色 / 语义色
└────────────────────┘
```

- 一屏 3～5 个；等高、等宽、间距 16px；内边距 20px。
- **每个数字必须回答"对用户意味着什么"**：带对比、占比、阈值或下一步动作。
- 可点击时整卡可点并给悬停反馈，点击后跳到对应筛选后的列表页。
- 禁止：巨型数字 + 装饰图形的大屏式卡片；无意义的数字。

## 5. StatusBadge（状态徽标）

- 结构：8px 圆点 + 文字（13px）+ 语义色；底色用对应语义色的 10% 低饱和版本。
- 高度 20～24px，左右内边距 8px，圆角 4～6px。
- 状态→颜色映射固定（见 `design-tokens.md` §1.3）；**状态不能只靠颜色**——必须带文字，色盲用户也能识别。
- 同一状态在表格、抽屉、首页必须完全一致。

## 6. DataTable（数据表格）

| 方面 | 规格 |
|---|---|
| 表头 | 13px/500 次要色，底 `--color-surface-alt`，高 40px，无粗重背景 |
| 行 | 高 44～52px（默认 48）；分割线 1px `--color-divider`；悬停 `#F9FBFF` |
| 列序 | 状态 → 关键标识（编号/名称）→ 业务字段 → 时间 → 操作 |
| 操作列 | 最右，固定不平移；文字按钮（查看/处理/编辑）+ "更多"收纳次要操作；每行最多 2 个直接可见操作 |
| 长文本 | 单行截断 + 悬停/详情查看全文，不换行撑高行 |
| 数字 | 右对齐、等宽数字；数量/金额带必要单位 |
| 排序/筛选 | 需要时表头可排序，用箭头图标指示方向 |
| 选中 | 选中行主色浅底 + 左侧色条；批量操作条在表格顶部出现 |
| 空/加载/错误 | 替换表体，表头保留（见 `states-feedback.md`） |
| 禁止 | 塞入全部字段；表头大字号/彩色；行高低于 44px；操作列在最左 |

## 7. SearchBar / FilterBar

- 搜索框 240～320px，带清除按钮；筛选下拉高 36px。
- 筛选条与表格间距 16px；"重置"为 Secondary 文字按钮。
- 筛选结果数量在表格上方或分页器处明示（`共 128 条`）。
- 有筛选条件时提供"已筛选"的可见反馈，避免用户误判数据缺失。

## 8. Drawer（详情抽屉）

- 宽 450～600px；遮罩 + 右侧滑入；`Esc` 关闭；仅左侧圆角。
- 头部固定（标题 + 关闭），中部滚动（信息分组），底部固定操作条。
- 打开时列表仍可见，**后台刷新不得关闭它**；抽屉内如有编辑，未保存时关闭需确认。
- 同屏只开一个抽屉；需要对比两条时用独立页面而不是两个抽屉。

## 9. Dialog（弹窗）

- 只用于：需明确确认的操作（删除、终止）、必须立即决策的紧急业务、短表单（≤5 个字段）。
- 宽度 400～560px；标题 16～18px；主操作在右；危险操作用 Danger 色且默认焦点不在危险按钮上。
- **禁止**：用弹窗展示长表单或大量信息（用抽屉/页面）；连续弹窗打断工作。

## 10. 按钮

| 类型 | 样式 | 场景 |
|---|---|---|
| Primary | 主色底 + 白字，高 34～38px，圆角 8px | 确认/保存/提交/处理（**每页仅一个**） |
| Secondary | 白底 + 1px 边框 + 主要文字色 | 取消/返回/查看/重置 |
| Danger | 红色底（或红字白底，项目内统一） | 删除/终止/撤销 |
| Text/Link | 无边框主色文字 | 表格行内操作、次级入口 |
| Disabled | 灰底/灰字 + 不可点，`cursor:not-allowed` | 权限不足或前置条件未满足，需给出原因提示 |

- 按钮文案用动词，不加"确定/OK"这类含糊词。
- 图标 + 文字按钮用于高频操作（新增 +、刷新 ↻）；纯图标按钮必须有 tooltip。
- 加载中按钮显示 loading 且禁止重复提交。

## 11. Toast / Notification

- 位置：右上角，宽 300～360px，2～5 秒自动消失（错误/需操作的通知不自动消失）。
- 类型：成功（绿）、警告（橙）、错误（红）、普通信息（灰/蓝）；最多同屏 3 条，超出排队。
- 重要通知 = Toast + 导航 Badge；异常 = 明显但不持续弹窗；紧急业务才用弹窗。
- 文案结构：**发生了什么 + 下一步**（如"保存失败，请检查网络后重试"）。

## 12. 图标

- 统一图标库（推荐 Lucide；WPF 用 Segoe Fluent Icons / MahApps 图标包），同一风格、线宽、视觉尺寸（16/18/20/24）。
- **禁止 Emoji 充当正式 UI 图标**（✅ ⚠️ 📦 等一律替换为矢量图标）。
- 语义固定：新增 `+`、刷新 `↻`、删除 垃圾桶、编辑 铅笔、查看 眼睛、更多 `…`、异常 三角叹号。

## 13. 组件状态矩阵（每个交互组件都必须实现）

| 组件 | Default | Hover | Focus | Active/Selected | Disabled | Loading | Error | Empty |
|---|---|---|---|---|---|---|---|---|
| 按钮 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | — | — |
| 输入框 | ✓ | ✓ | ✓ | ✓ | ✓ | — | ✓ | — |
| 表格 | ✓ | 行悬停 | — | 行选中 | — | ✓ | ✓ | ✓ |
| 抽屉 | — | — | ✓ | — | — | ✓(内容) | ✓(内容) | ✓(内容) |
| 卡片列表 | ✓ | ✓ | — | ✓ | ✓ | ✓ | ✓ | ✓ |

新增组件时必须补齐这张表里适用的状态，缺状态视为未完成。
