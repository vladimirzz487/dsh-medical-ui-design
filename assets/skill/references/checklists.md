# 可勾选清单（四套）

每条都能被客观回答"是/否"。任一项为"否"时，要么修掉，要么在交付说明中写明理由。

## A. 新增页面

- [ ] 已判定页面类型（工作台 / 列表 / 详情 / 表单 / 统计），并采用 §4 对应配方
- [ ] 沿用现有外壳：左导航 210～240px、顶栏 56～68px、主区留白 24px（未自造新框架）
- [ ] 页面标题出现在顶栏与页面内容处，措辞与导航项一致
- [ ] 一级导航仍 ≤7 项；新增入口放在合适层级而非都堆一级
- [ ] 页面的"一级信息"在 3 秒内可辨识（字号/对比明显高于其它信息）
- [ ] 只出现一个 Primary 按钮
- [ ] 颜色、字号、间距、圆角全部来自 token，无硬编码一次性值
- [ ] 正文字号 ≥12px，且未大量使用 12px
- [ ] Loading / Empty / Error / Disabled / Permission 全部实现
- [ ] 若为列表页：筛选条 + 表格 + 分页齐备；状态列靠前、操作列最右
- [ ] 若为详情：使用抽屉（450～600px）并做了信息分组
- [ ] 若为表单：标签明确（无 Placeholder 顶替 Label），校验错误就近提示
- [ ] 1366×768 下主流程可完整完成，无遮挡、无横向溢出（除表格内部滚动）
- [ ] 与既有页面同风格、同组件、同状态色语义（无"新页面新风格"）
- [ ] 未触碰 §12 禁止事项
- [ ] 已运行 `scripts/ui-audit.mjs` 并通过（或逐条解释保留项）

## B. 新增 / 改动功能

- [ ] 已回答业务四问：谁使用、每天最常做什么、最重要的信息、最重要的操作
- [ ] 该功能是否真的需要新入口？可否并入既有页面的待办/操作列
- [ ] 高频操作是否 ≤2 步可达（不藏在三级菜单或"更多"深处）
- [ ] 是否需要进入首页工作台（属于"待处理/异常/重要提醒"级别吗）
- [ ] 是否需要系统状态或实时数据（连 HIS/LIS/PACS/数据库/API 时必须有状态与最后同步时间）
- [ ] 操作结果有明确反馈（成功/失败/部分成功）
- [ ] 危险操作有二次确认并说明后果
- [ ] 无权限用户不会看到"能点但报错"的入口
- [ ] 涉及患者信息时遵循最小必要原则，敏感字段已脱敏
- [ ] 新增状态已在状态→颜色映射表中登记，颜色与既有语义一致
- [ ] 不会引入新的重复操作（如同一个"处理"在三个地方各写一遍逻辑而交互不一致）

## C. 加字段 / 改表格列 / 改表单

- [ ] 该字段是"快速判断需要"还是"详情才需要"？后者不进主表
- [ ] 主表列数是否过多（超过约 8 列需精简或分组）
- [ ] 状态字段保持靠前；新字段插入位置符合"状态→标识→业务→时间→操作"顺序
- [ ] 列宽按内容权重分配；长文本截断 + 可查看全文
- [ ] 数字右对齐、等宽数字、带单位
- [ ] 表单字段有明确 Label、必填标识与校验规则
- [ ] 字段属于敏感信息吗？是则脱敏或按权限显示
- [ ] 新增字段后表格在 1366×768 下仍可用（必要时降级为横向滚动）
- [ ] 导出/详情/列表三处的字段口径一致（不出现列名各异）

## D. 界面改版 / UI 走查

- [ ] 用 `scripts/ui-audit.mjs` 扫描目标目录，记录违规项
- [ ] 逐条核对 §12 禁止事项：渐变、玻璃拟态、过度圆角、巨型数字、过多动画、高频弹窗、Emoji 图标、彩虹色、无意义图表、密集堆砌、<12px 正文、全功能首页、复杂视觉特效
- [ ] 状态色是否被大面积使用（卡片整块变色）
- [ ] 同一状态在不同页面颜色是否一致
- [ ] 是否存在多个 Primary 按钮 / 按钮文案含糊（"确定/OK"）
- [ ] 空/加载/错误态是否缺失或被"白屏 + 转圈"糊弄
- [ ] 是否存在整页刷新、闪烁、滚动跳动、输入丢失、详情被关、编辑被覆盖
- [ ] 顶栏是否被塞入业务按钮；导航是否被塞入功能
- [ ] 图标是否统一库、统一线宽；有无 Emoji 混入
- [ ] 阴影是否过重（应优先边框）
- [ ] 1366×768 与 1920×1080 两个分辨率是否都验证过
- [ ] 改版后是否仍保留"打开即知当前状态与待办"的能力

## E. 交付说明模板

改版/新增完成后，用三句话说明：

1. **改了什么**：页面/组件/字段，以及对应的 token 与配方来源。
2. **为什么这样改**：涉及的 §1 铁律或 §7 业务判断。
3. **验证到什么程度**：跑了哪些检查（含审查脚本结论）、哪些分辨率/状态被实际验证，哪些未验证。
