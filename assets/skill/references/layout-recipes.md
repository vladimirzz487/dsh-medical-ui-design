# 布局配方与尺寸（含 1366×768 适配）

所有配方都以 §2 外壳为前提：**左导航 + 顶栏 + 主工作区**。改版时只动主工作区，保持外壳稳定。

## 1. 外壳

```
┌───────────────────────────────────────────────────────────────────────┐
│ 页面标题            HIS ●正常 17:32  🔔3  管理员 ▾          Header 60px │
├──────────────┬────────────────────────────────────────────────────────┤
│ Logo/产品名   │  主工作区 padding 24px                                  │
│ ───────────  │  ┌──────────────────────────────────────────────────┐  │
│ 工作台        │  │ 卡片区（白底 / 1px 边框 / 圆角 10px / padding 20）│  │
│ 核心业务 ▾    │  └──────────────────────────────────────────────────┘  │
│ 业务记录      │                                                        │
│ 消息提醒(3)   │                                                        │
│              │                                                        │
│ ● 系统正常    │                                                        │
│  Navigation  │                                                        │
│  220px       │                                                        │
└──────────────┴────────────────────────────────────────────────────────┘
```

- 导航项高 40～44px，左内边距 16px，图标 18px + 文字 14px；当前项：`--color-primary-soft` 底 + 主色文字 + 左侧 3px 主色条。
- 二级菜单只在需要时展开，最多两层；**一级导航超 7 项必须分组**。
- 导航底部固定显示系统状态（`● 系统正常` / `● 连接异常`），异常时可点击进入连接详情。
- 主工作区独立滚动；左导航与顶栏固定不滚动。

## 2. 工作台首页

```
页面标题（22px/600）
系统状态条：HIS ●正常 最后同步 17:32:18 | LIS ●正常 | PACS ●连接异常 [重新连接]
┌──────────┐┌──────────┐┌──────────┐┌──────────┐   ← 3～5 个统计卡片，等高，间距 16px
│ 待处理    ││ 处理中    ││ 今日新增  ││ 今日完成  │
│   18     ││   6      ││   24     ││   21     │
│ ↑较昨日3 ││ 需当日清零││ —        ││ 完成率87%│
└──────────┘└──────────┘└──────────┘└──────────┘
核心待办 ─────────────────────────────────────  ← 最突出：列表 + 行内操作按钮
│ ● 待处理  202609250018  内科  09:31  50  [处理] │
│ ● 异常    202609250017  外科  09:12  12  [处理] │
最近任务/业务列表 ─────────────────────────────
│ ● 处理中  202609250016  骨科  08:50  30  [查看] │
最近记录 ─────────────────────────────────────
```

要点：
- 统计卡片内边距 20px，主数字 28～32px/600，标签 13px 次要色，对比行 12px 辅助色。
- **核心待办的位置、宽度、对比度都必须高于其它区块**；用户的主要工作是处理待办时，待办列表上移、图表下移或删除。
- 首页默认不加复杂图表；确需图表时放在待办之后，高度不超过一行卡片。
- 首页不允许塞入所有功能入口（§12 禁止事项）。

## 3. 业务列表页

```
页面标题 + [新增]（唯一 Primary）          ← 右上操作区
[搜索框 240～320px] [科室 ▾] [状态 ▾] [日期 ▾] [重置]   ← 筛选条，高 40px，间距 12px
┌──────────────────────────────────────────────────────────────────┐
│ 状态 │ 编号 │ 科室 │ 时间 │ 数量 │ 操作                          │  ← 表头 13px 次要色，底 #F9FAFB
├──────────────────────────────────────────────────────────────────┤
│ ●待处理│202609250018│内科│09:31│ 50 │ 查看 处理                    │  ← 行高 48px
│ ●处理中│202609250017│外科│09:12│ 12 │ 查看                         │
└──────────────────────────────────────────────────────────────────┘
                                    共 128 条  ‹ 1 2 3 … ›  20 条/页
```

- 状态列最左、操作列最右；操作列宽 120～180px，固定不参与横向滚动。
- 表格容器自身滚动，页面滚动条不因表格行数变化而跳动。
- 每页 20 条（数据密集业务 50 条）为默认；分页器右对齐。
- 空/加载/错误态替换表格主体，筛选条与标题保留（见 `states-feedback.md`）。

## 4. 详情抽屉

```
                                        ┌──────────────────────────┐
                                        │ 详情                    × │  520px
                                        ├──────────────────────────┤
                                        │ 基础信息                  │  分组标题 16px/600
                                        │ 编号：202609250018        │  标签列 88～110px 次要色
                                        │ 科室：内科                │
                                        │ 时间：09:31               │
                                        │ ───────────────────       │
                                        │ 业务信息                  │
                                        │ ……                        │
                                        │ ───────────────────       │
                                        │ 操作信息 / 备注           │
                                        ├──────────────────────────┤
                                        │              [关闭] [处理] │  底部固定操作条
                                        └──────────────────────────┘
```

- 宽度 450～600px；从右侧滑入 200～240ms；遮罩 `rgba(17,24,39,.35)`。
- 内容区独立滚动，底部操作条固定；**打开期间后台刷新不得关闭抽屉、不得覆盖正在编辑的内容**。
- 一律用抽屉替代"每次弹新窗口"；只有业务确实复杂（多标签、多子表）才升级为独立页面。
- 抽屉内信息必须分组（基础/业务/操作/备注），组间用 24px 间距 + 分割线 + 小标题。

- 单列表单（桌面端不做双列，除非字段极多且相关性强）；输入框宽 320～480px。
- 校验错误就近显示在输入框下方 12px 处，红色 12～13px，写明原因与修正方式。
- 长表单分组 + 组标题；底部操作条吸底。

## 6. 1366×768 适配

| 变化 | 处理 |
|---|---|
| 主区变窄 | 卡片由 4 列 → 2 列；筛选条允许换行 |
| 宽度不足 | 减少次要列（如"备注""创建人"）→ 表格横向滚动 |
| 高度不足 | 降低区块间距 24→16px；卡片内边距 20→16px；表格仍保证 ≥44px 行高 |
| 绝不 | 把左导航变成移动端底部 Tab；把桌面表格变成卡片流；隐藏核心待办 |

检查清单：标题、关键按钮、状态、操作列在 1366×768 下**必须无横向遮挡**且无需缩放即可完成主流程。
